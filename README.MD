# تحليل مبيعات Superstore

المشروع ده تحليل لداتا مبيعات متجر (Superstore) من موقع Kaggle، حوالي 9800 صف، باستخدام SQL Server وبايثون.

## عملت إيه

1. نزّلت الداتا واستوردتها في SQL Server في جدول اسمه `sales`.
2. كتبت 5 queries وحطيتهم في ملف `queries.sql`.
3. وصلت بايثون بنفس الداتا وعملت التحليل في ملف `analysis.ipynb`.
4. رسمت charts للنتايج.

## أهم النتايج

- فئة Technology هي الأعلى مبيعًا.
- المبيعات بتزيد من 2015 لـ 2018، وبتعلى في آخر كل سنة.
- منتج Canon imageCLASS 2200 هو الأكتر مبيعًا بفرق كبير.

## تنضيف الداتا

لقيت 11 صف فيهم `Postal_Code` فاضي، كلهم لمدينة Burlington. سبتهم لأنهم قليلين ومش محتاجهم في التحليل.

## الملفات

- `queries.sql`: الـ 5 queries
- `analysis.ipynb`: التحليل والـ charts
